Portfolio case study - Product engineering

Sustain Ledger Partners

A multi-tenant GST invoicing platform built end to end: FastAPI backend, React web app and a Capacitor-wrapped Android app, deployed on Google Cloud as a shared SaaS for multiple independent companies.

sustainledger.inFastAPI - PythonReact 18 - ViteFirestoreCloud RunCapacitor / Android

01Overview

A GST-compliant invoicing SaaS for small and mid-size Indian businesses. One platform instance serves many independent companies from shared infrastructure, each with its own branded invoices, user accounts, customer/catalog data and Google Drive-backed document storage, isolated at the data layer and run from one superadmin console.

I designed and built the full stack solo: API design, data model, authentication, PDF generation, cross-platform delivery (web + native Android) and the GCP deployment pipeline, then operated it in production.

03API integrations

GCF

Google Cloud Firestore

Primary datastore for companies, users, invoices, customers, catalog items, drafts, usage snapshots and platform billing, all namespaced per tenant.

GD

Google Drive API (service account)

Each company's generated invoices are archived to a Drive folder shared with the platform's service account, with per-company storage quotas enforced before generation.

@

SMTP (Gmail)

Invoice delivery by email from one sending mailbox with a per-company display name, configured live from the superadmin console and backed by Firestore settings.

WA

Meta WhatsApp Cloud API

Invoice delivery over WhatsApp using a pre-approved business-initiated message template, authenticated via a Cloud API access token and phone-number ID.

JWT

Custom JWT auth

Role-based session tokens (superadmin / company_admin / company_user) with a temp-password, forced-reset onboarding flow and an opt-in long-lived "remember me" session.

CR

Cloud Scheduler to internal webhook

Twice-daily, machine-triggered usage snapshot (Firestore doc counts/sizes plus Drive usage per company) for the superadmin billing dashboard, secret-gated against unauthenticated triggers.

04Key functions built

GST invoice generation

Server-rendered PDF invoices with GST-compliant line items, tax breakdown and per-company branding; live preview before issuing.

Multi-tenant company management

Superadmin console to onboard companies, set business type, storage quotas, contact details and Drive folder links.

Role-based staff accounts

Superadmin, company admin and company user roles with scoped permissions and self-service password resets.

Customer & catalog management

Per-company customer directory and an item/service catalog with categories, reused across invoices.

Saved invoice drafts

Any staff member can save and resume an in-progress invoice before it's finalized and numbered.

Sequential invoice numbering

Financial-year-aware invoice counters with a next-number preview before submission.

GST-claim Excel export

Filterable (date range, customer, staff member, financial year) spreadsheet export for GST return filing.

Invoice delivery

One-click email or WhatsApp delivery of a finalized invoice directly to the customer.

Usage & cost dashboard

Superadmin view of per-company Firestore/Drive usage, configurable cost rates and generated platform cost reports.

Native Android app

Capacitor-wrapped build with Keystore-backed token storage, native PDF share/save and an in-app update checker for sideloaded APK releases.

Offline-aware invoicing

Network-failure detection distinguishes "offline" from a real validation error so in-progress invoices can be queued and retried.

Storage quota enforcement

Per-company Drive storage ceilings block invoice generation gracefully once exceeded, pending a manual increase.
