03API & service integrations

DRIVE

Document storage & automated archival

Multi-folder integration (per-business archive and backup folders, reimbursement bills, medical certificates) with a scheduled sweep job that archives completed sheets to Drive once every record clears billing, then purges the live Firestore copies.

GROQ

LLM-assisted document parsing

Groq-backed extraction used in the SDS intake pipeline for pulling structured chemical/product data out of uploaded PDFs.

FIRESTORE

System of record

All workflow, HR and billing data. TTL in-memory caching layers on every hot read path brought Firestore read volume down from a millions-per-day trajectory to a sustainable baseline.

MICRO

sarn-pdf-tools and sarn-scanner

Two companion Cloud Run services the main backend calls over HTTP for PDF utility operations and document scanning, kept independently deployable from the core API.

04Key functionality shipped

Workflow engine

Multi-pipeline document processing

Three parallel workflows - SLA/SDS (Search, Supersede, Transcription, Billing), Data Queue and Batch - each with stage-based assignment, rework/report loops and billing-readiness gating.

HR - Attendance

Geofenced check-in + leave engine

Self-service geofence check-in, admin overrides, half-day and hours-based Out of Office handling, and a monthly-accrual leave balance engine with per-type (SL/CL) breakdown and balance-aware payroll splitting.

HR - Payroll

Auto-generated payslips

Computed from attendance and leave data and rendered onto the company's real letterhead PDF via a pdfkit + pdf-lib overlay pipeline, with single and consolidated multi-month downloads.

Reporting

Role-scoped dashboards & exports

Separate Admin / Super Admin report views with cron-refreshed snapshot caching (10:00 and 17:00 IST), bulk repository-number lookup, and styled Excel/PDF exports.

Finance

Reimbursement & approval routing

Multi-item voucher submissions with auto-numbered, FY-scoped voucher IDs, approval-time locking, and manager-based request routing between employees, admins and Super Admin.

Platform

Role-based access control

SuperAdmin / Admin / User role tiers enforced at the route level (200+ API endpoints), with per-feature permission flags layered on top.
